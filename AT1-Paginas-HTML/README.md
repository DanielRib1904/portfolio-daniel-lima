# 🎬 AT1 Site Temático Multi-Páginas

## 📝 Descrição do Projeto

Este projeto consiste no desenvolvimento de um site estruturado em 5 páginas navegáveis e interligadas por um menu principal, desenvolvido a partir da base criada na aula de 02/09/2026. O objetivo principal é consolidar as boas práticas de navegação web, organização de arquivos e estruturação semântica.

Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End Para Web (2026.2)**, o site utiliza um tema definido com conteúdo real distribuído em 5 seções distintas. A aplicação foi construída com foco na acessibilidade e semântica HTML, além de integrar recursos visuais como imagens em formato JPG integradas diretamente ao corpo das páginas (`<body>`).

## 🚀 Tecnologias Utilizadas

* **Linguagem:** HTML5 e CSS
* **Bibliotecas:** Bootstrap
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados

O projeto permitiu exercitar a construção de sites institucionais/temáticos completos, garantindo consistência visual e facilidade de navegação.

* **Estrutura Semântica:** Uso correto de tags como `<header>`, `<nav>`, `<main>`, `<article>`, `<section>` e `<footer>` para melhor acessibilidade e SEO.
* **Navegação Relativa:** Criação de um menu de navegação funcional conectando as 5 páginas de forma fluida.
* **Mídia e Conteúdo Real:** Incorporação e otimização de imagens JPG no corpo das páginas para enriquecer a experiência do usuário com informações autênticas.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte tecnológico para auxílio na organização das tags semânticas e geração da estrutura inicial das páginas HTML. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
